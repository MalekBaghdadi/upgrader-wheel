# Upgrader Wheel - built-in pack value list (RLCraft Dregora)
#
# This list ships inside the mod and is updated with it. To change a value, add a line to
# config/upgraderwheel-pack.txt instead: your lines win over these.
#
# Values for things recipes cannot price: boss and mob drops, loot, dragon parts, special potions.
# Everything crafted from these is priced from them automatically (a dragon bone sword is 2 dragon bones
# and a witherbone), so fixing one raw material fixes everything made from it.
#
# Format:   modid:item = value          (all variants)
#           modid:item:meta = value     (one variant)
#           modid:prefix_* = value      (* matches any text; *:*text* matches any mod)
#           ore:oreDictName = value
#           potion:modid:type = value   (a potion type, drinkable bottle; splash:, lingering:, arrow: for the others)
#           modid:item = nowin          (can still be bet, but is never offered as a result)
# Values:   a number, or 2d = 2 diamonds, 3i = 3 iron ingots, 1g = 1 gold ingot, 1e = 1 emerald
#
# Scale: iron ingot 1024, gold ingot 2048, diamond 8192, emerald 16384, ender pearl 1024, nether star 139264.

# ---------------------------------------------------------------- Potions
# Every brewed potion with an effect is worth at least potionValue (config, default 4 gold = 1 diamond).
# Splash, lingering, long and strong versions are worked out from these through their brewing recipes
# (each step is worth what goes in x 1.25), and potions brewed from costly ingredients (Diamond Skin from a
# diamond block, Mending from a dragon heart) price themselves. Only the special ones are listed here.
